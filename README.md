# Eric Kinyua — Odoo Developer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy
- **Netlify:** Drag the folder (or ZIP contents) into Netlify Drop.
- **GitHub Pages:** Push the files to a repository, then enable Pages from the repository settings.
- **Vercel:** Import the repository and use the default static-site settings.

## Before publishing
1. Add your LinkedIn profile URL in `index.html` (search for `https://www.linkedin.com/`).
2. Add your CV as `assets/Eric-Kinyua-CV.pdf` and add a download link if you want it publicly available.
3. Review project summaries and ensure they reflect work you are comfortable sharing publicly.
4. If you have approved project screenshots, add them to the project cards.
5. Confirm the phone number, email and other contact details.

The website uses Google Fonts from the Google Fonts CDN. It remains functional if those fonts cannot load.
